How the method works

What happens in each federated round, and what the privacy setting does and does not promise.

The problem

Several campuses want a better model without pooling research data. Their data differs (non-IID), their data quality differs, and they may even use different model architectures, so averaging weights is not an option.

One round

  1. Local training. Each campus trains its own model on private data.
  2. Anchor prediction. Each campus predicts on a shared public anchor set. Only these predictions can leave the campus.
  3. Privacy protection. Gaussian noise is added to every prediction vector before it is sent.
  4. Trust estimation. The coordinator measures how uncertain each campus's predictions are (normalised entropy H) and converts that into a trust share.
    Tk = softmaxk( −mean Hk / τ ), smoothed across rounds
  5. Trust-weighted teacher. For every anchor sample, campuses are weighted by trust and by their own certainty on that sample.
    wk(x) ∝ Tk · exp(−Hk(x) / τs), q(x) = Σk wk(x) pk(x)
  6. Adaptive distillation. Each campus learns from the teacher while still fitting its own data.
    loss = CE(local batch) + λk · T² · KL(qT ‖ pT) on anchor samples, weighted by teacher confidence
    λk is larger for campuses the federation trusts less, and the whole value shrinks when the teacher itself is uncertain.
    λk = Q · λmax · ( floor + (1 − floor)(1 − Tk / max T) ), Q = mean teacher confidence
  7. Evaluation. Every campus is scored on a common held-out test set.

The baselines

  • Local only: no sharing, same total training epochs.
  • Uniform FD: every campus has the same weight, fixed λ (FedMD-style).
  • Trust + fixed λ: isolates the effect of adaptive distillation.

What the privacy number means

Noise is calibrated with the analytic Gaussian mechanism for a chosen (ε, δ). The guarantee is per released prediction vector, per round: it bounds how much any single released vector can reveal about the campus model's output. Across rounds the coordinator reports the tighter of basic and advanced composition. This is output perturbation, not DP-SGD, so it is not a formal record-level guarantee for each training example. Treat ε as a tunable privacy–utility dial and describe it that way in your report.

Known limitations

  • Entropy-based trust rewards confidence. A campus that is confidently wrong would be over-trusted; the “trust vs released accuracy” correlation on each run shows how well the signal tracks quality.
  • Noise is added in probability space, so very small ε makes every campus look uncertain and trust differences shrink.
  • The anchor set is assumed to be public and identically available to all campuses.
